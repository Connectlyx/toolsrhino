# SEO launch checklist for toolsrhino.com

## Do this week
1. **Google Search Console**: add the property (Domain method via DNS is best), then submit `https://www.toolsrhino.com/sitemap.xml`. Use "URL Inspection" > "Request indexing" for the home page, /services, /management-systems, /ai-automation and each industry page.
2. **Bing Webmaster Tools**: import the site from Search Console (takes one minute).
3. **One canonical domain**: in Vercel > Settings > Domains, make `www.toolsrhino.com` the primary and redirect `toolsrhino.com` to it (the site's canonical tags use www).
4. **Google Business Profile** for Connectlyx / ToolsRhino if you have a business address or service area.
5. **Analytics**: enable Vercel Web Analytics (one click) or add Google Analytics, so you can see which pages bring visitors.

## Off-site (this is what moves rankings)
- Link ToolsRhino from connectlyx.com (footer and a "ToolsRhino" page or section): the single easiest strong link.
- Create profiles with a link back: LinkedIn company page, Instagram, Clutch, GoodFirms, DesignRush, Crunchbase, relevant software directories.
- Publish each Insights article on LinkedIn with a link back. Share in relevant communities when genuinely useful.
- Ask clients of the live Rice Mill system for a short testimonial and permission to name them; add a case study page.
- Guest posts or interviews on industry sites (milling, agri-business, SME software).

## Content rhythm
- 2 new Insights articles per month on questions your customers actually ask. Start with: "rice mill accounting software", "payroll for daily-wage staff", "how to digitise a clinic", "WhatsApp automation for gyms".
- Add a real case study with numbers as soon as one client agrees.
- Add real screenshots/short video of the Rice Mill portal to its industry page.

## Check monthly in Search Console
Queries and pages with impressions but few clicks (improve titles/descriptions); pages "Discovered, not indexed" (add internal links); Core Web Vitals report.
